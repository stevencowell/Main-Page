WOODLANDS CUTTING PACK

1. Extract the complete ZIP.
2. Open index.html for the illustrated guide, or Woodlands-test-cut-guide.pdf for printing.
3. Start with files/Woodlands-TRIAL-400mm.dxf.
4. Only when happy, use files/Woodlands-FULL-800mm.dxf in a NEW SheetCam job.

Both drawings use millimetres and assume 3 mm mild steel. The 400 mm trial has 38 closed contours; the 800 mm sign has 39. The original full-size file has not been scaled or changed.

These files are CAD geometry, not a machine-ready TAP. Use the completed machine setup record and verified SheetCam post/tool. The guide contains the exact staged process and course sources.
