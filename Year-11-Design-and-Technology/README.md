# Year 11 Design and Technology

Repository-ready student learning site for the NSW Design and Technology Stage 6 Preliminary course.

## Build summary

- 15 two-week modules across 30 teaching weeks
- 45 theory sections
- 450 checked multiple-choice questions with option-level feedback
- 45 saved written responses
- 10 local evidence-folio cards
- 20 independent Busy Work activities
- Year 11 120-hour teaching program in HTML, DOCX and PDF
- Stage 6 240-hour master program in HTML, DOCX and PDF

## Authority boundary

The current NESA syllabus, current school assessment/task documents, and teacher-approved practical and WHS instructions remain authoritative. This site does not set task dates, final requirements, workshop access, adjustments, marking decisions or safety procedures.

The completed Year 12 course and detailed program now supply the HSC half of the two-year master. The HTML block map remains a compact continuity overview.

## Deployment

This is a static site. Publish the repository root with GitHub Pages or serve it with any static web server. No build step is required.

## Privacy and storage

Question attempts, completion markers, written responses and practice folio entries use browser localStorage. They remain on the device until exported or cleared.
